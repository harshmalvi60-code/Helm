How to fix

  1. 01
    Create a Supabase project
    Visit supabase.com → New project. Copy the URL, anon key and service-role key from Settings → API.
  2. 02
    Apply the schema
    Either paste supabase/schema.sql into the Supabase SQL Editor, or set SUPABASE_PROJECT_REF + SUPABASE_ACCESS_TOKEN locally and run npm run setup.
  3. 03
    Create a Shopify Partner app
    partners.shopify.com → Apps → Create app. Set callback URL to https://your-domain/api/integrations/shopify/callback
  4. 04
    Add env vars in Vercel
    Project → Settings → Environment Variables → paste each variable listed below. Redeploy when done.

Required env vars

SUPABASE_URL=https://xxx.supabase.co
SUPABASE_ANON_KEY=eyJ...
SUPABASE_SERVICE_ROLE_KEY=eyJ...
HELM_OAUTH_SECRET=<openssl rand -hex 32>
SHOPIFY_CLIENT_ID=<from Shopify partner app>
SHOPIFY_CLIENT_SECRET=<from Shopify partner app>
